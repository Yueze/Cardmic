Cardmic

Turn an M5Stack Cardputer ADV into a microphone. Driverless over USB, wireless over Wi-Fi.

Install from your browser

For the Cardputer ADV, and the original Cardputer from 0.6.0.

  1. Plug the Cardputer into this computer with a USB-C cable that carries data.
  2. Leave it on the stock launcher menu. (If it is not detected: power off, hold G0, plug in, release.)
  3. Click Install and pick the USB JTAG/serial debug unit port.
Your browser cannot talk to USB devices. Use Chrome or Edge on a desktop. Open this page over HTTPS to install. Source on GitHub

Installs M5Stack's factory firmware with the Cardmic app added: the stock launcher and apps stay. The stock settings (such as saved Wi-Fi) are reset. After this, updates install over Wi-Fi from Cardmic > Settings > About.

USB

Nothing to install on the computer. Pick "Cardmic Microphone" as the input.

Wi-Fi

Run the cardmic client with BlackHole (macOS) or VB-CABLE (Windows).

Hold to talk

Hold Space to hold your dictation app's hotkey, over USB.

Private

Pair once with a code on the screen; wireless audio is then encrypted.
